# 하네스 평가

## 목적

- 하네스 규칙이 실제 작업에서 일관되게 적용되는지 확인
- 하네스 문서 변경 시 관련 시나리오의 기대 행동과 충돌하는 부분이 없는지 검토
- 문서 검토와 실제 실행 결과를 구분하며, 실행 검증은 별도 테스트 저장소에서 진행

## 결과 기록

- 시나리오별로 아래 항목을 기록
  1. 실행 날짜와 평가 대상 하네스 버전 또는 커밋
  2. 테스트 저장소의 기준 커밋과 재현 조건
  3. 요청 내용과 실제 Agent 행동
  4. 실행 명령, 결과, 확인 가능한 로그나 diff
  5. 판정(통과/실패/미실행)과 기대 행동과의 차이
- 문서 검토만 진행한 경우 실행 판정은 미실행으로 기록
- 관련 시나리오가 모두 통과한 경우에만 해당 범위의 실행 검증 완료로 보고
- 실패 항목은 규칙이나 실행 환경을 수정한 뒤 다시 검증
